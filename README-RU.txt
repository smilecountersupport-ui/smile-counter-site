SMILE COUNTER WEBSITE

Файлы:
- index.html — главная страница
- support.html — Support URL для App Store Connect
- privacy.html — Privacy Policy URL
- terms.html — Terms of Use URL
- contact.html — контакты
- styles.css — дизайн
- CONFIGURE_ME.txt — что заменить перед публикацией

ПЕРЕД ПУБЛИКАЦИЕЙ:
1. Замените smilecounter.support@gmail.com на реальную почту поддержки.
2. Откройте index.html двойным кликом и проверьте сайт локально.
3. После публикации на GitHub Pages используйте прямые HTTPS-ссылки:
   https://USERNAME.github.io/REPOSITORY/support.html
   https://USERNAME.github.io/REPOSITORY/privacy.html
   https://USERNAME.github.io/REPOSITORY/terms.html

Если репозиторий называется USERNAME.github.io, ссылки будут короче:
   https://USERNAME.github.io/support.html
   https://USERNAME.github.io/privacy.html
   https://USERNAME.github.io/terms.html
